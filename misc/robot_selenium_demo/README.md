# Robot Selenium demo

Tämä on demoprojekti Robot Frameworkin SeleniumLibraryn testaukseen.

## Ajaminen

```bash
./server.js
```

## Automaattitestaaminen

### Virtuaaliympäristö

```bash
python3 -m venv robot-env/
source ./robot-env/bin/activate
pip install -r requirements.txt
```

Deaktivointi:

```bash
deactivate
```

```bash
robot
```
